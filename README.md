# Bastiaan's Wii Examples
Some Wii homebrew example programs

## Triangles
A simple Hello World test program that draws some triangles with display lists

## Triangles Rust
The same rotating triangle grid written in Rust with [ogc-rs](https://github.com/rust-wii/ogc-rs)

Install Rust nightly with the `rust-src` component and the devkitPro Wii toolchain, then run `make` in `triangles-rs`.

## Canvas
A larger example that show 2D rendering, PNG image loading, font rendering, cursor rendering
